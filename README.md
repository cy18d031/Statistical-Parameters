# Statistical
# Statistical Measures in Count and Point Process Descriptions of Enzyme Turnover

This repository contains Python programs that compute various statistical measures describing enzyme turnover reactions using two equivalent stochastic descriptions:

- **Count Process**: Tracks the number of product molecules formed up to time `t` → denoted by `n(t)`
- **Point Process**: Tracks the times of individual turnover events → denoted by `𝜏₁, 𝜏₂, ..., 𝜏ₚ`

The figure below illustrates the correspondence between these two representations:

![Count and Point Process Illustration](figures/count_vs_point1.png)


## Repository Contents

The root directory contains **statistical quantifiers** computed from trajectories generated by stochastic simulations (SSA), arranged by their dependence on:

- Fundamental probabilities
- Mean measures
- Fluctuation measures

A subfolder `count_and_point_example/` contains illustrative plots comparing count and point statistics for the same enzyme trajectory.

---

## Program Categories

### 🔹 Fundamental Quantities

| File Name               | Description                      |
|------------------------|----------------------------------|
| `P_n_t.py`             | Computes $P(n, t)$ — probability of having `n` products at time `t` |
| `T_p.py`               | Computes distribution of `Tₚ` — time of the `p`-th turnover |
| `turnover_dist.py`     | Computes distribution of turnover times (`τₚ = Tₚ - Tₚ₋₁`) |

---

### 🔹 Mean Measures

| File Name                   | Description                             |
|----------------------------|-----------------------------------------|
| `mean_vs_time.py`          | $\langle n(t) \rangle$ — mean product count over time |
| `mean_turnover_time_vs_p.py` | $\langle T_p \rangle$ — mean time of the `p`-th turnover |
| `ratio_mean_vs_t.py`       | Mean ratio $\langle n(t) \rangle / t$ |

---

### 🔹 Fluctuation Measures

| File Name                 | Description                              |
|--------------------------|------------------------------------------|
| `variance_vs_time.py`    | Variance of product count over time      |
| `CV_vs_time.py`          | Coefficient of variation in `n(t)`       |
| `C_t_lagged_corr.py`     | Lagged correlation function $C(\tau)$    |
